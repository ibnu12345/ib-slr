2. Panduan Langkah Demi Langkah Pengujian Transaksi (Test Flow)
  1. Langkah 1: Masuk ke Platform (Login)
    Buka peramban (browser) dan akses alamat https://ib-slr-app.vercel.app/login. Masukkan alamat email dan kata sandi di atas, lalu klik “Masuk ke Akun”.
  2. Langkah 2: Menuju Bagian Pembayaran / Top-Up
    Setelah berhasil masuk ke halaman dashboard/workspace, verifikator dapat mengakses fitur pembayaran melalui salah satu cara berikut:
    • Klik menu “Pricing” pada bilah navigasi utama (atau di halaman utama).
    • Atau klik tombol “Top Up Project Pass” / “Upgrade Plan” pada kartu kuota proyek di panel atas dashboard.
  3. Langkah 3: Pemilihan Paket & Klik Bayar
    Pilih salah satu paket layanan, misalnya paket Pay-Per-Project Pass (Rp 20.000) atau Professional Researcher (Rp 450.000), lalu tekan tombol “Beli Sekarang” / “Top Up”.
  4. Langkah 4: Munculnya Antarmuka Pembayaran Midtrans Snap
    Jendela pop-up atau antarmuka modal checkout Midtrans akan langsung terbuka secara otomatis di layar. Verifikator dapat melihat metode pembayaran yang tersedia (QRIS Nasional, Virtual Account Bank, dan E-Wallet) dan mengonfirmasi bahwa inisiasi transaksi berjalan lancar tanpa hambatan.
